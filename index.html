MakLom

Shared volunteer roster, attendance event log, tags, deduplication, review, analytics, and export tool.

How MakLom works

MakLom uses an authenticated shared database so authorised staff can access the same volunteer records from different computers.

Use Upload to import a roster or attendance event log template. MakLom validates headers, previews rows, and stages clean records, conflicts, and suspected duplicates for review before saving.

Use Merge Review to add tags, batch-edit staged rows, resolve conflicts, and confirm the import. Use Central Database to search and edit profiles. Use Event Log to view and edit the main attendance list.

Use Form Attendance for external sign-in/sign-out form data. New source responses are saved automatically, review flags are retained, and the source submissions remain separate from the Central Database and Event Log.

Use Dashboard to review volunteer counts, recruitment by year, deployment by year, programme participation, and manual reporting figures.

Use Export to download portable, redacted, event-log, merge-log, or JSON backup files. Exported files may contain personal data and should be handled securely.
